# Arduino Line Follower Robot

A basic autonomous line-following robot built using an Arduino Nano,
TB6612FNG motor driver, QTR-8RC line sensor array, and DC geared motors.

![Line Follower Robot](./images/line-follower-robot.jpg)

## Demo

The robot was tested on a competition track with different turns and
line-following sections.
